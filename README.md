# Física – 9º Ano · Óptica e Olho Humano (Mentoria Educacional Promover)

Reflexão, espelhos, refração, lentes, olho humano, problemas de visão e instrumentos ópticos: teoria ilustrada, simuladores, 18 questões com explicação e **relatório de erros pelo WhatsApp** para (85) 99262-1003.

## Publicar no GitHub Pages
1. Envie `index.html`, `style.css`, `dados.js`, `ilustracoes.js`, `widgets.js` e `app.js` para a raiz do repositório.
2. Vá em **Settings → Pages → Deploy from a branch**, escolha `main` e `/ (root)` e clique em **Save**.

## Editar
- Questões e teoria ficam em `dados.js` (`c` é a alternativa correta: 0=A … 3=D).
- O número do WhatsApp fica no início de `app.js` (`WHATSAPP`).
